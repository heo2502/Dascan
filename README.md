# 다스캔

ChatGPT, Gemini, Claude를 한 화면에서 사용하고 같은 질문을 동시에 보내 비교하는 Windows 데스크톱 앱입니다.

## 주요 기능

- 세 AI 서비스를 한 화면 또는 개별 탭으로 보기
- 한 입력창에서 선택한 AI 또는 모든 AI에 동시 질문
- 현재 대화의 교차검토 및 종합 요청
- 이미지 생성 프롬프트 동시 전송
- 찬성·반대·사회자 역할의 AI 토론 시작
- 쿠팡·네이버쇼핑·당근 동시 상품 검색
- 서비스별 로그인 세션을 로컬 PC에 유지

## 1.0.1 수정 사항

- Claude의 Google·Apple 로그인 팝업을 앱 내부의 동일 세션에서 열도록 수정
- Gemini와 Claude가 가상 입력 이벤트를 무시하던 문제를 실제 키보드 입력 방식으로 변경
- ChatGPT·Gemini·Claude별 최신 입력창과 보내기 버튼 선택자 적용

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

## Windows 설치 파일 만들기

```bash
npm run dist
```

설치 파일은 `release/Dascan-Setup-버전-x64.exe`로 생성됩니다.

## 사용 방법

1. 앱을 실행하고 ChatGPT, Gemini, Claude에 각각 로그인합니다.
2. 상단의 `모든 AI에게 질문하기`에 질문을 입력하고 Enter를 누릅니다.
3. 상단 탭으로 한 서비스만 크게 보거나 `전체`에서 답변을 나란히 비교합니다.
4. `교차검토`, `종합`, 왼쪽의 이미지·토론·쇼핑 모드를 활용합니다.

## 주의

이 앱은 각 AI 서비스의 웹 화면을 사용합니다. 서비스의 화면 구조가 바뀌면 자동 입력 기능의 선택자 조정이 필요할 수 있습니다. 각 서비스의 이용약관과 사용량 제한을 준수하세요. 로그인 정보는 외부 서버로 전송하지 않으며 Electron의 서비스별 로컬 세션에 저장됩니다.
