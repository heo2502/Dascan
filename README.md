# 다스캔

ChatGPT, Gemini, Claude를 한 화면에서 사용하고 같은 질문을 동시에 보내 비교하는 Windows 데스크톱 앱입니다.

## 주요 기능

- 세 AI 서비스를 한 화면 또는 개별 탭으로 보기
- 한 입력창에서 선택한 AI 또는 모든 AI에 동시 질문
- 현재 대화의 교차검토 및 종합 요청
- 이미지 생성 프롬프트 동시 전송
- 찬성·반대·사회자 역할의 AI 토론 시작
- 쿠팡·네이버쇼핑·당근 동시 상품 검색
- 서비스별 로그인 세션을 로컬 PC에 유지

## 1.0.1 수정 사항

- Claude의 Google·Apple 로그인 팝업을 앱 내부의 동일 세션에서 열도록 수정
- Gemini와 Claude가 가상 입력 이벤트를 무시하던 문제를 실제 키보드 입력 방식으로 변경
- ChatGPT·Gemini·Claude별 최신 입력창과 보내기 버튼 선택자 적용

## 1.1.0 AI 토론

- ChatGPT 찬성 측, Gemini 반대 측, Claude 사회자 역할 자동 배정
- 상대 발언과 사회자 평가를 다음 라운드에 자동 전달
- 실제 토론처럼 상대의 강한 논거 요약, 재반박, 약점 인정과 보완을 반복
- 사회자가 `[토론 종료]`를 선언하거나 최대 2~5라운드에 도달할 때까지 진행
- 최종 사회자 답변에 조건부 결론, 남은 불확실성, 실제 선택 권고 포함

## 1.1.1 프로그램 제거

- Windows 설정의 설치된 앱과 제어판에 `다스캔` 제거 항목 등록
- 시작 메뉴와 바탕화면 바로가기 지원
- 앱 왼쪽 아래 휴지통 버튼에서 제거 프로그램 실행
- 제거 전 확인 창 제공, AI 로그인 데이터는 기본적으로 보존

## 1.1.2 토론 진행 수정

- Gemini·Claude 답변 탐지 선택자를 확장하고 페이지 전후 텍스트 차이 방식 추가
- 첫 라운드에서 사회자가 조기 종료하지 못하도록 최소 2라운드 보장
- 찬성·반대 측에 상대 주장을 직접 요약·반박하도록 강제
- Claude가 자신의 주장을 하지 않고 양측 질문과 공정한 평가만 수행하도록 역할 강화
- 현재 기다리는 AI와 라운드를 진행 표시줄에 구체적으로 표시

## 1.1.3 토론 문맥 초기화

- 토론 시작 시 ChatGPT·Gemini·Claude를 각각 새 대화로 자동 초기화
- 이전 일반 질문이나 실패한 토론의 문맥이 찬성·반대·사회자 역할을 오염시키는 문제 방지

## 1.1.4 Gemini 자동 진행 수정

- Gemini가 `다음 토론 단계를 선택해 주세요`라는 추천 선택지를 생성하지 않도록 응답 규칙 강화
- Gemini 추천 버튼과 다음 단계 안내 영역을 실제 토론 발언에서 제거
- Gemini 답변을 사용자 입력 없이 Claude와 다음 라운드에 자동 전달
- 전송 후 입력창이 비워지지 않으면 Enter 방식으로 한 번 자동 재시도

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

## Windows 설치 파일 만들기

```bash
npm run dist
```

설치 파일은 `release/Dascan-Setup-버전-x64.exe`로 생성됩니다.

## 사용 방법

1. 앱을 실행하고 ChatGPT, Gemini, Claude에 각각 로그인합니다.
2. 상단의 `모든 AI에게 질문하기`에 질문을 입력하고 Enter를 누릅니다.
3. 상단 탭으로 한 서비스만 크게 보거나 `전체`에서 답변을 나란히 비교합니다.
4. `교차검토`, `종합`, 왼쪽의 이미지·토론·쇼핑 모드를 활용합니다.

## 주의

이 앱은 각 AI 서비스의 웹 화면을 사용합니다. 서비스의 화면 구조가 바뀌면 자동 입력 기능의 선택자 조정이 필요할 수 있습니다. 각 서비스의 이용약관과 사용량 제한을 준수하세요. 로그인 정보는 외부 서버로 전송하지 않으며 Electron의 서비스별 로컬 세션에 저장됩니다.
